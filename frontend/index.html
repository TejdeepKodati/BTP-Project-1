Simulation interpretation
Fixed volume, changing interactionsThe demand count is held constant for a selected data window; SUMO uses a fresh seed so departure times and resulting encounters can change between runs.
Incidents are not manually prescribedClose passes, hard braking and other detector events come from the simulated trajectories. A “safe pass” is an observed interaction state, not an incident.
Geometry mattersTurn-related events should only be reported where the actual road geometry supports a turn. The current controlled SUMO network is still a prototype and must be replaced/validated against the OSM corridor before geometry-specific claims are made.
